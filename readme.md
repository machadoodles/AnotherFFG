# Sitio Móvil de Family Gym

Abre `index.html` en un navegador o sirve esta carpeta localmente:

```bash
python3 -m http.server 4173
```

El sitio está pensado primero para móvil, se puede instalar como PWA e incluye acciones fijas, pestañas de programas, cuenta regresiva y confirmación del formulario de lista de espera.
